# Phosphorus

An interactive periodic table. Click any element to see its full profile — atomic mass, phase, electron configuration, discovery, and a summary.

## Run locally

No build step — it's a static site.

```bash
python -m http.server 5174
```

Then open http://localhost:5174

## Deploy

Static HTML/CSS/JS — works as-is on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Data

Element data adapted from the public domain [Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON) dataset.
